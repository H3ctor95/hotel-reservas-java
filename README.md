# Sistema de Reservaciones de Hotel

Este proyecto es un sistema de gestión de hotel desarrollado en Java, orientado a objetos, que permite la administración de reservaciones, habitaciones, huéspedes y más. El sistema se conecta a una base de datos para almacenar y gestionar la información.

## Características principales
- Gestión de habitaciones y tipos de habitación
- Registro y administración de huéspedes
- Creación y gestión de reservaciones
- Interfaz gráfica (Swing)
- Conexión a base de datos

## Estructura del proyecto
- `src/` — Código fuente Java, formularios y recursos
- `build.xml` — Script de construcción (Ant)
- `manifest.mf` — Archivo de manifiesto para el JAR
- `nbproject/` — Configuración del proyecto (excluyendo la carpeta `private/`)

## Requisitos
- Java JDK 8 o superior
- NetBeans (opcional, pero recomendado para abrir el proyecto)
- Base de datos compatible (ej. MySQL, SQLite)

## Configuración
1. Clona el repositorio:
   ```bash
   git clone <URL-del-repositorio>
   ```
2. Abre el proyecto en NetBeans o tu IDE favorito.
3. Configura la conexión a la base de datos en el archivo correspondiente (`ConectaDB.java`).
4. Compila y ejecuta el proyecto.
